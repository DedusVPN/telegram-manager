# 🤖 Telegram Account Manager Bot

Мощный бот для управления несколькими Telegram аккаунтами через единый интерфейс. Позволяет централизованно управлять отправкой сообщений, мониторить статистику и автоматизировать массовые рассылки.

## ✨ Возможности

### 📱 Управление аккаунтами
- Добавление неограниченного количества аккаунтов
- Автоматическая авторизация через код подтверждения
- Поддержка двухфакторной аутентификации
- Безопасное шифрование сессий
- Просмотр статуса всех аккаунтов

### ✉️ Отправка сообщений
- Массовая рассылка через несколько аккаунтов
- Поддержка Markdown форматирования
- Настраиваемые интервалы между сообщениями
- Задержки между аккаунтами для естественности
- Автоматические повторы отправки

### 📊 Аналитика
- Статистика успешных отправок
- Отслеживание ошибок и блокировок
- История всех сообщений
- Мониторинг активности аккаунтов

## 🚀 Быстрый старт

### Требования
- Python 3.11+
- Docker (опционально)
- Telegram Bot Token
- Telegram API credentials

### Установка

#### Метод 1: Docker (рекомендуется)

```bash
git clone https://github.com/Justhateme0/Telegram-Account-Manager-Bot
cd telegram-account-manager
cp .env.example .env
nano .env
docker-compose up -d
```

#### Метод 2: Локально

```bash
git clone https://github.com/Justhateme0/Telegram-Account-Manager-Bot
cd telegram-account-manager
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python main.py
```

### Конфигурация

Создайте файл `.env` на основе `.env.example`:

```env
BOT_TOKEN=your_bot_token_from_botfather
API_ID=your_api_id_from_my.telegram.org
API_HASH=your_api_hash_from_my.telegram.org
ADMIN_ID=your_telegram_user_id
ENCRYPTION_KEY=generate_32_character_key
```

#### Получение credentials:

1. **BOT_TOKEN**: Получите у [@BotFather](https://t.me/botfather)
2. **API_ID & API_HASH**: Создайте приложение на [my.telegram.org](https://my.telegram.org)
3. **ADMIN_ID**: Ваш Telegram ID (можно узнать у [@userinfobot](https://t.me/userinfobot))
4. **ENCRYPTION_KEY**: Сгенерируйте 32-символьный ключ:
   ```python
   from cryptography.fernet import Fernet
   print(Fernet.generate_key().decode())
   ```

## 📖 Использование

### Команды бота

- `/start` - Главное меню
- `📱 Аккаунты` - Управление аккаунтами
- `✉️ Сообщения` - Создание и отправка сообщений
- `📊 Статистика` - Просмотр статистики
- `📜 История` - История отправленных сообщений

### Добавление аккаунта

1. Нажмите `📱 Аккаунты` → `➕ Добавить аккаунт`
2. Введите номер телефона в формате `+79123456789`
3. Введите код подтверждения из Telegram
4. При необходимости введите пароль 2FA
5. Аккаунт готов к использованию!

### Создание рассылки

1. Нажмите `✉️ Сообщения` → `✏️ Создать сообщение`
2. Введите целевой чат (username или ID)
3. Выберите аккаунты для отправки
4. Напишите текст сообщения с Markdown
5. Настройте параметры:
   - Количество повторов
   - Интервал между сообщениями
   - Задержка между аккаунтами
6. Рассылка запустится автоматически!

### Форматирование текста

Поддерживается Markdown синтаксис:

```markdown
**Жирный текст**
*Курсив*
`Моноширинный код`
[Ссылка](https://example.com)
```

Пример:
```markdown
**Специальное предложение!**

*Только сегодня* скидка 50%!

[Подробнее](https://example.com)
```

## 🔒 Безопасность

- Все сессии шифруются с использованием Fernet (симметричное шифрование)
- Данные хранятся локально в защищенной базе данных
- Автоматическая обработка flood-wait ограничений
- Защита от банов через рандомизированные задержки

## ⚠️ Ограничения

- Соблюдайте лимиты Telegram API
- Используйте разумные интервалы между сообщениями (минимум 10 секунд)
- Не отправляйте спам - это нарушает ToS Telegram
- Рекомендуется использовать не более 5-10 аккаунтов одновременно
